Léeme - VONA Visualizador de Avisos Volcánicos para Aviación
Raúl Antuña Suárez

1. Estructura del proyecto y contenido de las carpetas
- index.html: Interfaz principal con globo terráqueo 3D interactivo, panel de información de alertas aeronáuticas y selector de erupciones volcánicas.
- src/: Código fuente de la aplicación.
  - ts/: Módulos en TypeScript.
    - index.ts: Inicialización y orquestación de la aplicación.
    - vona_service.ts: Lógica de carga, parseo del XML VONA y vinculación con la capa geoespacial.
    - vona_validator.ts: Validación estructural y de campos requeridos del estándar VONA.
    - vona_types.ts: Tipos de datos e interfaces TypeScript para los avisos volcánicos.
  - wasm/:
    - vona_geodesy.wat: Módulo WebAssembly en formato texto que implementa algoritmos de geodesia y trigonometría esférica (fórmula de Haversine para distancias de gran círculo, cálculo de rumbos iniciales y límites de dispersión de ceniza).
    - build_wasm.js: Script de Node.js para compilar el archivo WAT a binario WASM.
- assets/: Recursos estáticos desplegados en el navegador.
  - ts/: Archivos JavaScript resultantes de la compilación de TypeScript ('tsc').
  - wasm/vona_geodesy.wasm: Binario compilado de WebAssembly.
  - js/: Scripts de integración (vona_wasm_engine.js, app.js, nav.js).
  - css/: Hojas de estilo modulares (base.css, layout.css, index.css) validadas.
  - samples/: Muestras de avisos volcánicos reales en formato XML conforme al estándar VONA (etna-vona.xml, eyjafjallajokull-vona.xml, kilauea-vona.xml, popocatepetl-vona.xml, sakurajima-vona.xml, tajogaite-vona.xml, multi-volcanoes-vona.xml).
- package.json y tsconfig.json: Configuración de dependencias de desarrollo y TypeScript.
- leeme.txt / léeme.txt: Este documento explicativo.


2. Procedimiento de despliegue de la aplicación
1. Compilar los archivos TypeScript ejecutando:
   npm run build   (o npx tsc)
2. (Opcional en caso de cambios en el código WAT): Recompilar el módulo WebAssembly:
   node src/wasm/build_wasm.js
3. Copiar la carpeta 'vona-xml' completa al directorio servido por el servidor web (/var/www/html/vona-xml/).
4. Servir la aplicación a través de un servidor HTTP/HTTPS (Apache, Nginx, etc.) para permitir la carga correcta de módulos ES6, ficheros XML locales y el streaming binario de WebAssembly.
5. Acceder mediante el navegador web a la ruta servida.


3. Software, herramientas y versiones utilizadas
- TypeScript 5.9.3 (compilador tsc).
- WebAssembly (WAT / WASM) para computación geodésica.
- WABT (WebAssembly Binary Toolkit, v1.0.34) para compilar WAT a WASM.
- MapLibre GL JS v5.1.0 (motor de renderizado cartográfico y globo terráqueo 3D mediante WebGL).
- Node.js (v20+ / v22+).
- Estándar aeronáutico: OACI Doc 9766 (Handbook on the International Airways Volcano Watch) y formato XML VONA.
- HTML5 y CSS3 nativos.
- Navegadores probados: Google Chrome 120+, Mozilla Firefox 120+, Apple Safari 17+ (con soporte WebGL 2.0 y WebAssembly).


4. Explicaciones y consideraciones específicas
- Integración de estándares internacionales aeronáuticos: La aplicación procesa avisos de observatorios vulcanológicos para la aviación civil (VONA), parseando y validando códigos de color de aviación (GREEN, YELLOW, ORANGE, RED), altitudes de columna de ceniza en pies y metros, y coordenadas geográficas.
- Motor de cálculo geodésico en WebAssembly: Las operaciones de trigonometría esférica de precisión para determinar distancias entre aeropuertos/rutas y el volcán emisor se delegan a un módulo compilado en WebAssembly (vona_geodesy.wat), optimizando los cálculos matemáticos intensivos en punto flotante de 64 bits (f64).
- Visualización 3D interactiva: Renderizado mediante MapLibre GL en proyección de globo terráqueo, permitiendo explorar las erupciones volcánicas activas, capas de dispersión y datos meteorológicos de aviación con fluidez gráfica.
