Léeme - Web Personal
Raúl Antuña Suárez

1. Tecnologías utilizadas y justificación
Para el desarrollo de la web personal he utilizado exclusivamente HTML5, CSS3 y JavaScript nativo (Vanilla), prescindiendo totalmente de frameworks (como React, Vue o Angular) y de librerías CSS (como Bootstrap o Tailwind).

El motivo principal de esta elección es garantizar el cumplimiento estricto de los estándares web fijados por el W3C y WHATWG:

- HTML5: La estructura de cada página está construida con etiquetas semánticas (header, nav, main, section, article, figure, footer, etc.) en lugar de abusar de contenedores genéricos (div y span). También se cuida la jerarquía de encabezados con un único h1 por vista y se añaden atributos ARIA donde procede para favorecer la accesibilidad.

- CSS3: He organizado los estilos de forma modular (base.css para variables y reset, layout.css para cabecera y pie comunes, y un css específico para cada página). Se emplean variables CSS nativas para mantener una paleta coherente, y CSS Grid y Flexbox junto con media queries en unidades relativas (rem) para que el diseño sea totalmente responsive. Además, todas las reglas definen tanto color como fondo para cumplir los requisitos de contraste y superar la validación del W3C sin fallos.

- JavaScript (ES6+): Se utiliza únicamente para la interactividad imprescindible (el menú hamburguesa en móviles en nav.js y el filtrado por categorías en projects.js). Al ser JavaScript nativo cargado con el atributo defer, no bloquea el renderizado de la página, no mete dependencias externas y asegura que el código funcione en cualquier navegador moderno sin herramientas de compilación.


2. Estructura del proyecto
- index.html: Portada y presentación general.
- about.html: Información personal, biografía y recursos multimedia (audio y vídeo).
- projects.html: Catálogo de proyectos destacados con filtro por categoría.
- cv.html: Currículum vitae con experiencia, estudios y enlace al PDF.
- contact.html: Formulario de contacto y enlaces a perfiles.
- assets/css/: Hojas de estilo CSS3 modulares.
- assets/js/: Scripts nav.js y projects.js.
- assets/img/, assets/audio/, assets/video/: Contenido multimedia de apoyo.
- assets/cv_raul_antuna.pdf: Currículum en PDF descargable.
- léeme.txt / leeme.txt: Este documento explicativo.
