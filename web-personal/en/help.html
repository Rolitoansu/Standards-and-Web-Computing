How to navigate

The website has a single navigation level with five main pages: Home, About me, Projects, CV and Contact. All of them are reachable from the top menu, which stays fixed while you scroll, and from the footer.

  • Current page: the menu link for the page you are on is highlighted in blue.
  • Breadcrumb: below the menu, on every inner page, a trail such as “Home › Projects” tells you where you are and lets you go back to the home page.
  • Site map: the site map links every page and each of its sections.
  • On mobile: the menu collapses behind the ☰ button in the top right corner. Press Esc or tap outside the menu to close it.
  • Back to the start: the “Raúl Antuña” name in the header always links to the home page.

How to search

The search box in the header (and the Search page) finds any content on the site: projects, technologies, companies, hobbies and so on. It runs entirely in your browser and sends nothing to any server.

  • It ignores case and accents: “formula 1” finds “Formula 1”.
  • It tolerates small typos: “Hiberus” is found even if you type “Hiverus”.
  • Results are sorted by relevance and show an excerpt with the matching terms highlighted.
  • If there are no results, the search suggests a correction (“Did you mean…?”) and alternatives.
  • Results update as you type; you can also press Enter.

Accessibility

This site is designed to meet level AA of the Web Content Accessibility Guidelines (WCAG) 2.1. Among other measures:

  • Semantic HTML with labelled landmark regions and a consistent heading hierarchy on every page.
  • A “Skip to main content” link as the first element of every page, visible when you press Tab.
  • Visible focus on every interactive element and a minimum colour contrast of 4.5:1 for text.
  • Alternative text for informative images; decorative images are marked as such.
  • The video has descriptive captions (English and Spanish) and each audio clip has an expandable transcript.
  • The mobile menu, the project filters and the contact form report their state to screen readers.
  • The system “reduce motion” preference is respected by disabling animations and smooth scrolling.
  • The layout adapts to any screen size and supports text zoom up to 200% without loss of content.

Keyboard navigation

Useful keys for moving around the site
Key Action
Tab / Shift + Tab Move forwards or backwards between links, buttons and fields.
Enter Activate the focused link or button; submit the form.
Space Press buttons (project filters, mobile menu) and tick checkboxes.
Esc Close the mobile menu and return focus to the ☰ button.
Tab when the page loads Reveal the “Skip to main content” link.

Screen readers and reader mode

Every page can be browsed by landmarks and headings. Search results, the filter state and form messages are announced through aria-live regions. In the browser's reader mode all content is preserved, including the links to the project repositories.

Languages

The website is available in English and Spanish. To switch language use the “Español” link in the top menu or “Versión en español” in the footer; on the Spanish version you will find the “English” link in the same places. Each page links to its counterpart in the other language, so you never lose context when switching.

Browsers and search engines also receive hreflang tags, so they can offer you the version in your language directly.

Frequently asked questions

How do I download the CV as a PDF?

On the CV page you will find the “Download CV as PDF” button in the header. The file is about 250 KB and is written in Spanish.

How does the contact form work?

The form validates your data in the browser and, when submitted, opens your email application with the message already written and addressed to me. If you prefer not to use it, you can write directly to rolitoansu@outlook.com. No data is stored on the site.

Does the website work without JavaScript?

Yes. All content, navigation and the form work without JavaScript. Only the internal search and the project filtering need it; you can use the site map instead.

Why won't the video or audio play?

The video is in MP4 (H.264) format and the audio clips in MP3, both supported by current browsers. If your browser cannot play them, each player includes a link to download the file.

Which browsers has it been tested in?

In the latest versions of Chrome, Firefox, Safari and Edge, on desktop and mobile. The HTML and CSS validate without errors in the W3C validators.

Can I contact someone who can vouch for your work?

Yes. The References section of the CV lists the people who can vouch for my background and how to request their contact details.

Report a problem

If you find a broken link, content that does not display correctly or an accessibility barrier, I would be grateful if you let me know:

  1. Use the contact form and select the reason “Report a website issue”.
  2. Mention the page, the browser you use and, if possible, the steps to reproduce the problem.
  3. You can also write directly to rolitoansu@outlook.com.

I aim to reply and fix accessibility problems within two weeks at most.
