1. DESCRIPCIÓN DEL PROYECTO
--------------------------------------------------------------------
Este proyecto consiste en el diseño y desarrollo de un sitio web personal
y profesional completo. El sitio actúa como portal de presentación,
portfolio de proyectos de software, currículum vitae estructurado y canal
de contacto profesional.

El diseño visual es moderno, responsivo y adaptativo, ofreciendo una
experiencia fluida tanto en dispositivos móviles como en pantallas de
escritorio.


2. TECNOLOGÍAS UTILIZADAS Y JUSTIFICACIÓN DE SU ELECCIÓN
--------------------------------------------------------------------
Para el desarrollo del sitio se ha tomado la decisión deliberada de utilizar
exclusivamente tecnologías web nativas (Vanilla):

  - HTML5 (Estructura y semántica)
  - CSS3 (Presentación y maquetación visual)
  - JavaScript ES6+ (Comportamiento e interactividad)

Se ha prescindido por completo de frameworks pesados (como React, Angular,
Vue, Tailwind CSS o Bootstrap) y de librerías o dependencias de terceros.

A continuación se detalla la justificación técnica de esta elección:

a) Garantía de estricto cumplimiento de estándares web (W3C y WHATWG):
   El objetivo primordial de la asignatura es comprender y aplicar con rigor
   los estándares web. El uso de frameworks y bibliotecas de abstracción suele
   introducir elementos propietarios, estructuras no semánticas (abuso de
   divs, clases utilitarias excesivas) o construcciones de difícil validación.
   El uso directo de los estándares nativos permite un control absoluto sobre
   el árbol DOM y el modelo de cajas, asegurando una validación 100% limpia
   frente a los validadores oficiales del W3C.

b) HTML5 Semántico y Accesibilidad Nativa (WCAG):
   - Cada página está construida con un esquema semántico riguroso: <header>,
     <nav>, <main>, <section>, <article>, <figure>, <figcaption>, <time>,
     <aside> y <footer>, evitando el uso superfluo de etiquetas <div> y <span>.
   - Jerarquía clara de encabezados (un único <h1> representativo por vista,
     seguido lógicamente de <h2> y <h3>).
   - Accesibilidad integrada mediante atributos ARIA estándar cuando resulta
     necesario (aria-label, aria-current="page", aria-expanded, aria-pressed,
     aria-hidden), garantizando compatibilidad con lectores de pantalla y
     navegación asistiva.
   - Uso de elementos multimedia nativos (<audio>, <video>) con controles
     estándar del navegador y alternativas textuales.

c) CSS3 Moderno, Modular y Mantenible:
   - Arquitectura CSS organizada y desacoplada:
     * base.css: Definición de variables globales (Custom Properties),
       normalización de estilos, escala tipográfica y diseño de componentes base.
     * layout.css: Estilos estructurales compartidos (cabecera global, menú
       de navegación responsivo y pie de página).
     * index.css, about.css, projects.css, cv.css, contact.css: Hojas de
       estilo dedicadas y optimizadas para cada una de las vistas.
   - Variables CSS (Custom Properties): Centralizan la paleta cromática,
     espaciados, radios de curvatura y transiciones, favoreciendo una
     mantenibilidad equivalente a preprocesadores (Sass/Less) pero de forma
     nativa en el navegador.
   - Maquetación avanzada: Empleo exhaustivo de CSS Grid y Flexbox para layouts
     flexibles y alineaciones precisas.
   - Diseño responsivo mediante media queries móviles (@media) con unidades
     relativas (rem, em), garantizando que el diseño responda a distintos
     tamaños de viewport y niveles de zoom sin romperse.
   - Contraste y legibilidad: Definición estricta y simultánea de propiedades
     `color` y `background-color` en todas las reglas para prevenir problemas
     de contraste visual y cumplir escrupulosamente con el validador CSS del W3C.

d) JavaScript Vanilla (ES6+) Ligero y No Bloqueante:
   - Interactividad modular y focalizada:
     * nav.js: Control del menú de navegación móvil (hamburguesa), conmutación
       del atributo `aria-expanded` y cierre reactivo al interactuar o redimensionar.
     * projects.js: Filtrado reactivo en tiempo real de proyectos por categoría
       (Web, Móvil, Sistemas/C, Todos), gestionando el estado `aria-pressed`
       de los botones y el filtrado del DOM mediante atributos `data-category`.
   - Cero dependencias: Manipulación directa del DOM con APIs nativas modernas
     (querySelector, classList, dataset, addEventListener), evitando sobrecargar
     el navegador con bundles de librerías.
   - Rendimiento de carga: Scripts cargados con el atributo `defer` en el <head>,
     lo que garantiza que la descarga sea asíncrona y la ejecución ocurra tras el
     parseo completo del documento, eliminando el bloqueo del renderizado.

e) Rendimiento, Cero Dependencias y Longevidad:
   - Al no requerir pasos de transpilación, compilación ni empaquetado (webpack,
     vite, babel), el código fuente es directamente ejecutable por el navegador.
   - El tiempo de carga (First Contentful Paint y Largest Contentful Paint) es
     inmediato, optimizando al máximo las métricas Core Web Vitals.
   - El código es atemporal: no sufre de obsolescencia ni de vulnerabilidades de
     seguridad asociadas a árboles de dependencias en npm.
