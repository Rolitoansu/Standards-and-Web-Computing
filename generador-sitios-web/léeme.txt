2. Estructura del proyecto y contenido de las carpetas
- index.html: Interfaz web de la herramienta para cargar el documento XML, validar y descargar el sitio web generado en un archivo ZIP.
- schema/: Definición del vocabulario XML.
  - sitio-personal.xsd: Esquema XML (W3C XML Schema) que define la sintaxis, tipos, elementos y restricciones estructurales de PersonalSiteML.
  - ESPECIFICACION_XML.md: Documentación detallada del esquema XML y ejemplos de uso.
- ejemplos-xml/: Archivos XML de ejemplo listos para probar el generador.
  - raul-antuna.xml: Sitio web personal completo de ejemplo.
  - elena-garcia.xml: Ejemplo alternativo (investigadora en IA).
  - marcos-sanchez.xml: Ejemplo alternativo (diseñador de producto).
- src/: Código fuente original de la aplicación.
  - ts/: Módulos TypeScript.
    - parser.ts: Parsea el DOM XML del archivo subido y extrae el modelo de datos.
    - validator.ts: Comprueba restricciones semánticas y consistencia lógica del XML.
    - generator.ts: Genera el código HTML5 semántico de las 5 páginas y copia los assets asociados.
    - index.ts: Punto de entrada de la lógica de interfaz y orquestación.
    - types.ts: Interfaces y tipos TypeScript del modelo.
  - wasm/:
    - xml_metrics.wat: Módulo WebAssembly en formato texto que computa métricas del XML (conteo de nodos, tamaño y caracteres).
    - build_wasm.js: Script Node.js para compilar el WAT a binario WASM usando wabt.
- assets/: Recursos estáticos servidos al navegador.
  - ts/: Archivos JavaScript compilados a partir de los fuentes TypeScript mediante 'tsc'.
  - wasm/xml_metrics.wasm: Binario compilado de WebAssembly.
  - js/: Librerías y scripts clientes (jszip.min.js para empaquetar el ZIP, wasm_runner.js y app.js).
  - css/app.css: Estilos visuales de la aplicación del generador.
  - img/: Iconos tecnológicos y recursos gráficos incluidos en el ZIP generado.
- package.json y tsconfig.json: Configuración de dependencias de desarrollo y compilador TypeScript.
- leeme.txt / léeme.txt: Este documento explicativo.


3. Procedimiento de despliegue de la aplicación
La aplicación ejecuta toda la lógica en el lado cliente del navegador (parsing XML, validación, cálculo WASM, generación HTML5 y empaquetado ZIP).
Para desplegar la aplicación:
1. Compilar el código TypeScript a JavaScript:
   npm run build   (o npx tsc)
2. (Opcional si se modifica el código WAT): Recompilar el módulo WebAssembly ejecutando:
   node src/wasm/build_wasm.js
3. Copiar la carpeta 'generador-sitios-web' completa al directorio servido por el servidor web (/var/www/html/generador-sitios-web/).
4. Es imprescindible servir la aplicación a través de un servidor HTTP/HTTPS (Apache, Nginx, etc.), ya que la carga de módulos ES6 y la instanciación de WebAssembly (WebAssembly.instantiateStreaming) requieren protocolo HTTP y tipos MIME adecuados (application/wasm y text/javascript), no funcionando mediante el protocolo local 'file://'.


4. Software, herramientas y versiones utilizadas
- TypeScript 5.9.3 (compilador tsc).
- Node.js (v20+ / v22+ para ejecución del build de TypeScript y WASM).
- WABT (WebAssembly Binary Toolkit, v1.0.34) para compilar de WAT a WASM.
- JSZip v3.10.1 (empaquetado de archivos ZIP en memoria del navegador).
- XML Schema 1.0 (XSD) y DOMParser nativo del navegador.
- HTML5 y CSS3 para la interfaz del generador.
- Navegadores probados: Google Chrome 120+, Mozilla Firefox 120+, Apple Safari 17+.


5. Explicaciones y consideraciones específicas
- Integración de WebAssembly: Se ha implementado un módulo en WebAssembly Text Format (xml_metrics.wat) para realizar el análisis de volumen y métricas del archivo XML cargado a nivel binario de alta eficiencia, comunicándose con la interfaz TypeScript mediante memoria lineal compartida.
- Cumplimiento de estándares en la salida generada: El generador produce un sitio web idéntico al solicitado en la práctica de web personal, generando 5 páginas HTML5 totalmente semánticas (index, about, projects, cv, contact) con marcado accesible, hojas de estilo CSS3 validadas y scripts nativos.
- Validación en dos niveles: 
  1. Sintáctica y estructural mediante el esquema XSD (sitio-personal.xsd).
  2. Semántica mediante validator.ts (consistencia de fechas, enlaces cruzados de categorías y datos obligatorios).
